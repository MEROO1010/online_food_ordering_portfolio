# Customer Behavior Analysis & Online Food Ordering Prediction

## Files
- `customer_behavior_analysis.ipynb`: end-to-end exploratory analysis and baseline classification workflow.
- `online food delivery dataset.csv`: original dataset provided for this project.

## Run
1. Install Python and Jupyter.
2. Install dependencies: `pip install pandas numpy matplotlib seaborn scikit-learn scipy jupyter`
3. Open the notebook in Jupyter.
4. Run cells from top to bottom.

## Notes
This dataset contains 388 rows. The notebook checks the duplicate `Unnamed: 13` column and removes it only if it exactly matches `Output`. Model results should be treated as exploratory due to the small sample and the need to confirm what `Output` means.
